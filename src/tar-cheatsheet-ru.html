Шпаргалка по tar и архивам

Создание и распаковка архивов, выбор сжатия, работа с отдельными файлами, передача архива по сети, а также zip и другие форматы.

Ключи в двух словах

-c / -x / -t
Создать, распаковать, показать содержимое
-f файл
Имя архива; идёт последним среди ключей
-v
Показывать имена файлов
-z / -j / -J
Сжатие gzip, bzip2, xz
-C каталог
Перейти в каталог перед работой
--exclude=шаблон
Пропустить файлы по маске

Мнемоника: create, extract, list; zip-сжатие, verbose, file.

Создать архив

tar -czf arc.tar.gz каталог
Сжатый gzip — самый ходовой вариант
tar -cJf arc.tar.xz каталог
Сильнее сжатие, дольше упаковка
tar -cf arc.tar каталог
Без сжатия: быстро, годится для уже сжатых данных
tar -czf arc.tar.gz -C /var/www site
Упаковать без длинного пути внутри архива
tar -czf arc.tar.gz --exclude='*.log' --exclude='.git' проект
С исключениями
tar -czf arc.tar.gz -T list.txt
Список файлов из файла
tar --exclude-vcs -czf arc.tar.gz проект
Пропустить служебные каталоги систем контроля версий

Распаковать

tar -xzf arc.tar.gz
В текущий каталог
tar -xzf arc.tar.gz -C /opt/app
В указанный каталог (он должен существовать)
tar -xzf arc.tar.gz path/to/file
Только один файл или каталог
tar -xzf arc.tar.gz --strip-components=1
Отбросить верхний уровень: частая нужда при распаковке релизов
tar -xzf arc.tar.gz --keep-newer-files
Не перезаписывать более свежие файлы
tar -xzf arc.tar.gz --wildcards '*.conf'
Распаковать по маске

Перед распаковкой в общий каталог загляните внутрь: tar -tzf arc.tar.gz | head. Архивы бывают «без корня» и рассыпают файлы по текущему каталогу.

Посмотреть и проверить

tar -tzf arc.tar.gz
Список содержимого
tar -tvzf arc.tar.gz
С правами, владельцем и размером
tar -tzf arc.tar.gz | wc -l
Сколько файлов внутри
gzip -t arc.tar.gz
Проверить целостность сжатия
tar -df arc.tar -C /path
Сравнить архив с файлами на диске

Полезные приёмы

# Архив с датой в имени
tar -czf backup-$(date +%F).tar.gz /data

# Копия каталога на другой сервер без промежуточного файла
tar -czf - /data | ssh user@host "tar -xzf - -C /restore"

# Забрать каталог с сервера
ssh user@host "tar -czf - /var/www" > site.tar.gz

# Многопоточное сжатие (быстрее на многоядерных машинах)
tar -cf - /data | pigz -p 8 > data.tar.gz

# Добавить файл в существующий несжатый архив
tar -rf arc.tar newfile.txt

# Сохранить права и владельцев при распаковке от root
tar -xzpf arc.tar.gz --same-owner

Другие форматы

zip -r arc.zip каталог / unzip arc.zip
Обмен с Windows; unzip -l — просмотр, -d — каталог назначения
gzip файл / gunzip файл.gz
Сжатие одного файла на месте
xz -9 файл / unxz
Сильное сжатие
zstd файл / unzstd
Современный вариант: быстрее xz при похожем сжатии
7z a arc.7z каталог
Формат 7-Zip, если нужен именно он

Что помнить

  • Имя архива идёт сразу после -f; перестановка — источник загадочных ошибок.
  • Абсолютные пути tar по умолчанию обрезает и предупреждает об этом: файлы распакуются относительно текущего каталога.
  • Права и владельцы сохраняются, но восстановить чужого владельца может только root.
  • Сжимать уже сжатое (видео, изображения, архивы) почти бесполезно — берите -cf без сжатия.
  • Для регулярных копий каталогов rsync с --link-dest экономнее, чем полный архив каждый раз.
  • Распаковка из недоверенного источника: проверьте список файлов, чтобы архив не записал что-то мимо ожидаемого каталога.

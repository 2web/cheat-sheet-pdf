Шпаргалка по OpenSSL

Ключи и сертификаты, запросы на подпись, проверка цепочки и срока действия, преобразование форматов, диагностика TLS-соединений, хеши и шифрование файлов.

Ключи

openssl genrsa -out key.pem 2048
Закрытый ключ RSA
openssl genpkey -algorithm ED25519 -out key.pem
Современный ключ на эллиптических кривых
openssl ecparam -genkey -name prime256v1 -out key.pem
Ключ ECDSA P-256
openssl rsa -in key.pem -pubout -out pub.pem
Извлечь открытый ключ
openssl rsa -in key.pem -noout -text
Посмотреть параметры ключа
openssl rsa -aes256 -in key.pem -out key-enc.pem
Зашифровать ключ паролем; обратно — без -aes256

Закрытый ключ — секрет: права 600, не класть в репозиторий, не пересылать почтой. Утёкший ключ считается скомпрометированным — выпускайте новый и отзывайте сертификат.

Запрос и сертификат

openssl req -new -key key.pem -out req.csr
Запрос на подпись (CSR) к удостоверяющему центру
openssl req -new -newkey rsa:2048 -nodes -keyout key.pem -out req.csr
Сразу ключ без пароля и запрос
openssl req -x509 -newkey rsa:2048 -nodes -keyout key.pem -out cert.pem -days 365
Самоподписанный сертификат — для тестов и внутренних служб
-subj "/CN=example.com/O=Компания"
Данные без интерактивных вопросов
-addext "subjectAltName=DNS:example.com,DNS:www.example.com"
Альтернативные имена: без них современные браузеры сертификат не примут
openssl x509 -req -in req.csr -CA ca.pem -CAkey ca.key -CAcreateserial -out cert.pem -days 365
Подписать своим удостоверяющим центром

Проверить и посмотреть

openssl x509 -in cert.pem -noout -text
Содержимое сертификата целиком
openssl x509 -in cert.pem -noout -subject -issuer -dates
Кому выдан, кем и на какой срок
openssl x509 -in cert.pem -noout -ext subjectAltName
Список имён в сертификате
openssl x509 -in cert.pem -noout -checkend 2592000
Истекает ли в ближайшие 30 дней — удобно для проверок в мониторинге
openssl req -in req.csr -noout -text
Проверить запрос перед отправкой
openssl verify -CAfile ca.pem cert.pem
Проверить цепочку доверия
openssl x509 -noout -modulus -in cert.pem | openssl md5
Сверить, что сертификат и ключ — пара (сравните с тем же для rsa -modulus)

Диагностика соединения

openssl s_client -connect example.com:443
Подключиться и показать цепочку сертификатов
-servername example.com
Указать имя для SNI: без него сервер отдаст не тот сертификат
-showcerts
Вся цепочка, включая промежуточные
| openssl x509 -noout -dates
Только срок действия предъявленного сертификата
-tls1_2 / -tls1_3
Проверить поддержку конкретной версии протокола
-starttls smtp
Для почтовых и других протоколов с переходом на TLS
openssl s_server -accept 4433 -cert cert.pem -key key.pem
Поднять тестовый TLS-сервер

Форматы и преобразования

PEM
Текстовый формат с заголовками BEGIN/END — самый распространённый
DER
Двоичный; openssl x509 -in cert.der -inform der -out cert.pem
PKCS#12 (.pfx, .p12)
Ключ и сертификаты в одном файле под паролем
openssl pkcs12 -export -out bundle.p12 -inkey key.pem -in cert.pem -certfile chain.pem
Собрать связку
openssl pkcs12 -in bundle.p12 -nodes -out all.pem
Разобрать обратно
cat cert.pem chain.pem > fullchain.pem
Полная цепочка для веб-сервера: сначала сертификат, затем промежуточные

Хеши и случайные данные

openssl dgst -sha256 файл
Контрольная сумма
openssl dgst -sha256 -hmac "ключ" файл
HMAC с секретом
openssl rand -hex 32
Случайная строка — годится для маркеров и секретов
openssl rand -base64 24
То же в base64
openssl passwd -6 "пароль"
Хеш пароля в формате /etc/shadow
openssl base64 -in файл / -d
Кодирование и декодирование base64

Подпись и шифрование файлов

# Подписать и проверить
openssl dgst -sha256 -sign key.pem -out file.sig file
openssl dgst -sha256 -verify pub.pem -signature file.sig file

# Зашифровать файл паролем
openssl enc -aes-256-cbc -pbkdf2 -salt -in file -out file.enc
openssl enc -d -aes-256-cbc -pbkdf2 -in file.enc -out file

# Зашифровать открытым ключом получателя (для небольших данных)
openssl pkeyutl -encrypt -pubin -inkey pub.pem -in secret.txt -out secret.enc

Для больших объёмов и обмена с людьми удобнее age или GnuPG: у них проще управление ключами и меньше шансов ошибиться с параметрами.

Частые задачи

  • Сертификат не подходит сайту — сверьте subjectAltName с именем в адресной строке.
  • Браузер ругается на цепочку — сервер отдаёт не все промежуточные: соберите fullchain.pem.
  • Ключ не подходит к сертификату — сравните хеши modulus у ключа и сертификата.
  • Скоро истекает — поставьте проверку -checkend в мониторинг и обновляйте заранее.
  • Самоподписанный на тесте — добавьте свой CA в доверенные на клиенте, а не отключайте проверку.

Шпаргалка по VIM

Режимы, перемещение, правка, поиск и замена, файлы и окна, буферы и вкладки, макросы и настройки. Команды даны для обычного режима, если не сказано иное.

Режимы

Esc
Вернуться в обычный режим — базовое действие, если что-то пошло не так
i / a
Вставка перед курсором / после курсора
I / A
Вставка в начале / в конце строки
o / O
Новая строка ниже / выше с переходом к вставке
v / V / Ctrl-v
Выделение: посимвольное, построчное, прямоугольное
R
Режим замены: печать поверх существующего текста
:
Командная строка редактора

Перемещение

h j k l
Влево, вниз, вверх, вправо
w / b / e
На слово вперёд / назад / в конец слова
0 / ^ / $
В начало строки / к первому непробельному символу / в конец
gg / G / 42G
В начало файла / в конец / к строке 42
Ctrl-d / Ctrl-u
Полэкрана вниз / вверх
{ / }
К предыдущему / следующему пустому абзацу
%
К парной скобке
f<символ> / t<символ>
К ближайшему символу в строке / перед ним; ; повторяет
Ctrl-o / Ctrl-i
Назад и вперёд по истории переходов

Правка

x / X
Удалить символ под курсором / перед ним
dd / D
Удалить строку / до конца строки
dw / d$ / d}
Удалить слово, до конца строки, до конца абзаца
cc / cw
Заменить строку / слово с переходом к вставке
yy / yw / p / P
Скопировать строку / слово; вставить после / перед курсором
u / Ctrl-r
Отменить / вернуть отменённое
.
Повторить последнее изменение — самая экономящая клавиша
J
Склеить текущую строку со следующей
>> / <<
Сдвинуть строку вправо / влево
~ / guu / gUU
Сменить регистр символа; строку в нижний / в верхний

Команда = действие + область

Команды складываются: d (удалить) + 2w (два слова) = d2w. Работают и «текстовые объекты»:

diw / ciw
Удалить / заменить слово под курсором целиком
di" / ci(
Внутри кавычек / внутри скобок
da" / ca(
То же вместе с кавычками или скобками
dap / yap
Абзац целиком: удалить / скопировать

Поиск и замена

/текст, затем n / N
Поиск вперёд, к следующему / предыдущему совпадению
?текст
Поиск назад
*
Найти слово под курсором
:%s/старое/новое/g
Замена во всём файле
:%s/старое/новое/gc
То же с подтверждением каждой замены
:10,20s/a/b/g
Замена только в строках 10–20; '<,'> — в выделении
:noh
Снять подсветку найденного
:g/шаблон/d
Удалить все строки со совпадением (:v/шаблон/d — оставить только их)

Файлы, выход

:w / :w файл
Сохранить / сохранить под другим именем
:q / :q!
Выйти / выйти без сохранения
:wq или ZZ
Сохранить и выйти
:e файл / :e!
Открыть файл / перечитать с диска, отбросив правки
:w !sudo tee %
Сохранить файл, открытый без нужных прав
:r файл / :r !команда
Вставить содержимое файла или вывод команды

Буферы, окна, вкладки

:ls / :b номер
Список открытых буферов и переход к нужному
:bn / :bp / :bd
Следующий, предыдущий, закрыть буфер
:sp файл / :vs файл
Разделить окно по горизонтали / вертикали
Ctrl-w h j k l
Переход между окнами
Ctrl-w = / Ctrl-w _
Выровнять размеры / развернуть текущее окно
:tabnew файл, gt / gT
Новая вкладка, следующая / предыдущая

Метки и регистры

ma, затем 'a
Поставить метку a и вернуться к ней
''
Вернуться туда, где были до последнего прыжка
"ayy / "ap
Скопировать в регистр a и вставить из него
"+y / "+p
Обмен с системным буфером обмена
:reg
Показать содержимое регистров

Макросы

qa … q
Записать последовательность действий в регистр a
@a / @@
Выполнить макрос / повторить последний
20@a
Выполнить 20 раз — обработка однотипных строк за один приём

Настройки

Разовые команды вводятся через :set, постоянные пишут в ~/.vimrc (для Neovim — ~/.config/nvim/init.vim).

:set number relativenumber
Номера строк, в том числе относительные
:set ignorecase smartcase
Поиск без учёта регистра, но с учётом, если введены заглавные
:set expandtab tabstop=4 shiftwidth=4
Отступы пробелами
:set hlsearch incsearch
Подсветка совпадений и поиск по мере ввода
:syntax on / :set wrap
Подсветка синтаксиса; перенос длинных строк
:set paste / :set nopaste
Вставка из буфера терминала без автоотступов

Если растерялись

  • Нажмите Esc — вы в обычном режиме, дальше :q! выходит без сохранения.
  • vimtutor в терминале — встроенный получасовой курс.
  • :help тема открывает документацию, Ctrl-] переходит по ссылке, Ctrl-o возвращает.
  • Число перед командой повторяет её: 3dd удалит три строки.
  • Файл открыт другим сеансом — Vim предупредит о swap-файле; безопасный выбор обычно «только для чтения».

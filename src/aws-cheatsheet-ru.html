Шпаргалка по AWS

Ключевые службы, настройка и команды AWS CLI, доступы IAM, вычисления и контейнеры, хранилища и базы данных, сеть, наблюдение и управление расходами.

Как устроено

  • Регион — географическая площадка (eu-central-1); зона доступности — независимый дата-центр внутри региона.
  • Аккаунт — единица изоляции и счёта; несколько аккаунтов объединяются в организацию.
  • IAM — пользователи, роли и политики: кому и что разрешено.
  • Роль — временные права, которые принимает служба или пользователь; предпочтительнее постоянных ключей.
  • Теги — метки ресурсов для учёта расходов и поиска.

AWS CLI

aws configure / aws configure sso
Настроить ключи или вход через единый доступ
aws sts get-caller-identity
Под кем вы сейчас работаете — первая команда при непонятных отказах
--profile prod --region eu-central-1
Профиль и регион для одной команды
--output table / --query "Reservations[].Instances[].InstanceId"
Формат вывода и выборка полей языком JMESPath
--dry-run
Проверка прав без выполнения (поддерживают многие команды EC2)
aws help / aws ec2 help
Встроенная справка

Доступы

aws iam list-users / list-roles
Пользователи и роли аккаунта
aws iam attach-role-policy --role-name app --policy-arn ...
Привязать политику к роли
aws sts assume-role --role-arn ... --role-session-name s1
Получить временные учётные данные
Политика
Документ JSON: Effect, Action, Resource, Condition

Осторожно: не создавайте постоянные ключи для служб — используйте роли. Корневую учётную запись защитите многофакторной проверкой и не работайте под ней.

Контейнеры: собственный оркестратор AWS и управляемый Kubernetes

Хранилища

aws s3 ls / aws s3 ls s3://bucket --recursive
Корзины и объекты
aws s3 cp file s3://bucket/path
Загрузка и скачивание файлов
aws s3 sync ./dist s3://bucket --delete
Синхронизация каталога; удаляет лишнее в приёмнике
aws s3 presign s3://bucket/file --expires-in 3600
Временная ссылка на приватный объект
Классы хранения
Standard, Infrequent Access, Glacier: дешевле хранение — дороже и медленнее доступ
EBS / EFS
Блочный диск для машины; сетевая файловая система для многих машин

Базы данных

Совместимые с PostgreSQL и MySQL базы с быстрым масштабированием чтения

Расходы

  • Включите бюджеты и оповещения в первый же день.
  • Исходящий трафик и NAT-шлюзы часто дают неожиданные суммы — проверяйте их отдельно.
  • Остановленная машина не тарифицируется по процессору, но диск и статический адрес оплачиваются.
  • Постоянная нагрузка дешевле с планами экономии, пакетные задачи — на спотовых машинах.
  • Cost Explorer с разбивкой по тегам показывает, какая команда или среда тратит больше.
  • Правила жизненного цикла S3 переводят старые объекты в дешёвые классы автоматически.

Частые ошибки

  • AccessDenied — не хватает прав у пользователя или роли; сверьте get-caller-identity и политику.
  • Ресурс «пропал» — скорее всего вы в другом регионе: почти всё в AWS региональное.
  • Нет доступа к машине — проверьте группу безопасности, таблицу маршрутов и публичный адрес.
  • Приватная подсеть без NAT-шлюза не имеет выхода в интернет — обновления пакетов не пройдут.
  • Имя корзины S3 уникально глобально; политика корзины и блокировка публичного доступа проверяются вместе.

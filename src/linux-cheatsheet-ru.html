Поиск

Выполнить команду для каждого найденного файла
grep -rn "текст" /etc

Где лежит исполняемый файл

Просмотр и правка текста

Диск и память

df -h
Свободное место по точкам монтирования
df -i
Иноды: место есть, а файлы не создаются — обычно дело в них
du -xh --max-depth=1 / | sort -h
Кто занял место, по каталогам верхнего уровня
free -h
Память; строка available важнее, чем free
lsblk / mount | column -t
Диски и разделы; смонтированные файловые системы
uptime / vmstat 1 / iostat -x 1
Средняя нагрузка; общая картина; нагрузка на диски

Сеть

Запросы к DNS

Только заголовки; тихая загрузка с выводом кода ответа

Проверить, открыт ли порт

Перехват пакетов для разбора

SSH и передача файлов

ssh user@host -p 2222
Подключение на нестандартном порту
ssh-keygen -t ed25519 / ssh-copy-id user@host
Создать ключ и положить его на сервер
~/.ssh/config
Сокращения для узлов: Host, User, Port, IdentityFile
ssh -L 5432:localhost:5432 user@host
Проброс удалённого порта на локальную машину
scp файл user@host:/путь
Копирование по SSH
rsync -avz --delete src/ user@host:/dst/
Синхронизация каталогов со сжатием; удаляет лишнее в приёмнике
rsync -avz --dry-run ...
Показать, что будет сделано, ничего не меняя

Осторожно: косая черта в конце источника у rsync значит «содержимое каталога». Без неё копируется сам каталог — частая причина неожиданной вложенности.

Расписание задач

crontab -e / crontab -l
Редактировать и посмотреть задания пользователя
*/15 * * * * /путь/script.sh
Каждые 15 минут. Поля: минуты, часы, день месяца, месяц, день недели
0 3 * * 1 команда
По понедельникам в 03:00
@reboot команда
При загрузке системы
systemd timer
Современная замена cron: systemctl list-timers

В cron скудное окружение: указывайте полные пути и перенаправляйте вывод в файл, иначе ошибки останутся незамеченными.

Когда что-то сломалось

  • Место кончилось — df -h, затем du -xh --max-depth=1 по подозрительным каталогам; не забудьте df -i.
  • Служба не поднимается — systemctl status и journalctl -u имя -n 100.
  • Порт занят — ss -ltnp покажет процесс.
  • Файл удалён, но место не освободилось — процесс держит дескриптор: lsof | grep deleted.
  • Высокая нагрузка — top, затем iostat и vmstat: упор может быть в диск, а не в процессор.
  • Права — ls -l и namei -l /полный/путь покажут, на каком уровне отказ.

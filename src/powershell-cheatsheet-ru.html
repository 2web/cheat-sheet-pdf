Как устроены команды

Имя командлета — это пара «Глагол-Существительное»: Get-Process, Set-Location, New-Item. По конвейеру передаются объекты, а не текст, поэтому у результата есть свойства.

Get-Command *service*

Get-Help Get-Process -Examples
Справка с примерами (-Full — целиком, -Online — в браузере)
Get-Member
Свойства и методы объекта: Get-Process | Get-Member
Get-Alias ls
Что скрывается за коротким именем

Условия и циклы

if ($count -gt 10) { "много" }
elseif ($count -eq 0) { "пусто" }
else { "мало" }

foreach ($item in $list) { $item }

for ($i = 0; $i -lt 5; $i++) { $i }

while ($queue.Count) { $queue.Pop() }

switch ($status) {
    "ok"   { "готово" }
    "fail" { "ошибка" }
    default { "неизвестно" }
}

Сравнения записываются словами: -eq -ne -gt -lt -ge -le -like -match -contains -in. Отрицание — -not или !, объединение — -and, -or.

Скрипты и функции

function Get-BigFiles {
    param(
        [Parameter(Mandatory)]
        [string]$Path,
        [int]$MinMB = 100
    )

    Get-ChildItem $Path -Recurse -File |
        Where-Object { $_.Length -gt $MinMB * 1MB } |
        Sort-Object Length -Descending
}

Get-BigFiles -Path C:\data -MinMB 500

Полезные привычки

  • Сначала посмотрите на объект через Get-Member — станет ясно, какие свойства можно фильтровать.
  • Format-* ставится только в конец: после него в конвейере остаётся текст, а не объекты.
  • Опасные действия проверяйте с -WhatIf.
  • Модули ставятся из галереи: Install-Module имя -Scope CurrentUser.
  • PowerShell 7 кроссплатформенный, команда запуска — pwsh; часть Windows-командлетов в нём недоступна.
